# 开发计划

本目录保存当前有效的开发计划。

| 计划 | 状态 | 范围 |
| --- | --- | --- |
| [订阅、积分包与计费改造](subscription-billing.md) | 执行中；部分业务规则待商榷 | 账本、收支入口、多窗口订阅、用量结算、权益标签、路由验证、页面及迁移 |
| [开发进度与验证证据](development-progress.md) | 第 1 轮完成 | 入口归属、运行结果与审查修复 |
| [账务验收与故障场景](accounting-verification.md) | 待实施的测试契约 | 具体输入、预期、故障断点、迁移样本与完成证据 |

当前按[12 轮开发、2 轮预留](subscription-billing.md#21-开发轮次估计)规划，在测试基线和业务规则确定后复核；每轮包含实现、测试与验收。

计划以[产品设计](../design/README.md)和[账户与计费设计](../design/accounting.md)为依据；涉及的待商榷业务规则在对应功能开发前确定。

每份计划应给出目标和关联需求、实施顺序、代码职责与修改范围、接口及数据约束、迁移与回退办法、先失败后通过的行为测试、验收证据。是否拆文件按理解成本判断，不按行数机械拆分。

完成并验证后的计划移至 [archive/plans/](../archive/plans/)。设计变更先更新当前设计，再同步执行计划，不以计划中的临时决定覆盖产品规则。
